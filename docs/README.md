## Root-level Status Files

- [`PROJECT_STATUS.md`](../PROJECT_STATUS.md) — current implementation/acceptance state
- [`AGENTS.md`](../AGENTS.md) — coding agent rules and document priority
- [`TASKS.md`](../TASKS.md) — current task queue and milestone

## Document Classification

- **Core** — normative, current architecture/specification/security documents
- **Features** — per-subsystem feature docs and their dated acceptance evidence
- **Local AI** — design proposals, benchmark plans, Stage A/B evidence, historical reviews
- **Releases** — release gate evidence and scope freeze records
- **Roadmap** — future plans and open questions
- **evidence/** subdirectories — dated acceptance reports, benchmark results, diagnosis records
- **historical/** subdirectories — superseded reviews and earlier benchmark runs
